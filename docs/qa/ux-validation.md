# UI 與設定驗收

## 自動檢查

在啟用 Android 開發環境後執行：

```sh
bash gradlew --no-daemon --max-workers=4 assembleDebug testDebugUnitTest lintDebug
```

`RestoreShotPolicyTest` 驗證刪箭復原的六種情境：保留原序號、新箭佔用序號、滿局、換局、當局已結束、重複復原。

## 裝置驗收清單

以下需以實際畫面與資料確認，不能以建置成功代替：

- 繁中切英文、英文切繁中：設定、訓練與數據頁立即更新；重啟後保留選擇與訓練資料。
- 相機權限拒絕：保留手動輸入；從應用程式設定授權返回後恢復相機。
- 建立訓練、未校正、已校正、辨識中、暫停與待確認：提示文字對應目前狀態。
- 手動新增兩箭，刪除最後一箭，再按復原：箭點、分數與資料庫一致；滿局或換局後不得恢復到錯誤局。
- 微調後滑掉底部面板：要求確認；取消保留草稿，放棄不改原箭點。
- 小螢幕（360dp 寬）、橫向與 200% 字體：主要操作可捲動到達，文字不覆蓋開關。
- 明暗模式：提示不只依靠顏色，箭點狀態有文字。
- 數據頁空資料不持續顯示載入；匯出標明未開放；比較只使用同距離同靶紙的基準。
- 實體手機：戶外陽光、腳架、校正、連續箭點辨識與 TTS；確認可讀性、辨識延遲與語音清晰度。

最後一項無法由雲端模擬器代替；必須在射箭場以實體裝置驗證。
